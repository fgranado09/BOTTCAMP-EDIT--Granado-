# Glosario
* Algoritmo:
  * Secuencia Ordenada y finita de pasos que resuelve un problema especifico o realiza uan tarea determinada
* Codigo Maquina:
  * Conjunto de instrucciones binarias que el procesador puede ejecutar directamente
* Compilador:
  * Programa que trauce el codigo fuente escrito en un lenguaje de programacion o codigo maquina para su ejecucion
* Depuracion:
  * Proceso de identificar, analizar y corregir errores en el codigo fuente de un programa.
* Expresion:
  * Combinacion de valores, variables y operadores que al evaluarse producen un resultado
* Funcion:
  * Bloque de codigo reutilziable que realiza una tarea especifica y puede recibir parametros y devolver valores
* IDE (Entorno de desarrollo integrado):
  * Editor de codigo especializado para escribir y editar codigo fuente, a travces de un software que proporciona herramientas completas para el desarrollo de programas.
* Imprimir:
  * Accion de mostrar informacion en la pantalla o en otro dispositivo de salida.
* Importacion:
  * Proceso de incluir modulos o bibliotecas externas en un programa para utilizar sus funciones
* Interprete:
  * Programa que ejecuta el codigo fuente directamente, traduciendo y ejecutando las instrucciones linea por linea
* Lenguaje de programacion:
  * Sistema estructurado de reglas y simbolos que permite crear programas informaticos
* Lenguaje tipado:
  * Lenguaje de programacion que requiere la declaracion explicita del tipo de datos para las variables
* Modularizacion:
  * Tecnica de dividir un programa en partes mas pequeñas y manejables llamadas modulos
* Operador:
  * Simbolo que indica una operacion a realizar sobre uno o mas operandos.
* Python:
  * Lenguaje de programacion de alto nivel, interpretado y de proposito general, conocido por su simplicidad y legibilidad / Es un Software que intrepreta y ejecuta programas escritos en lenguaje pyhton.
* Sintaxis:
  * Conjunto de reglas que definen como deben escribirse las instrucciones en un lenguaje de programacion
* Terminal:
  * Interfaz de texto que permite interactuar con el sistema operativo mediante comandos.
* Variable:
  * Espacio en memoria que almacena un vvalor y puede ser modificado durante la ejecucion del programa.
